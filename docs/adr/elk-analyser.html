觸發模式

  • Kibana Alert — Webhook 自動觸發（to_time + lookback_minutes）
  • Web UI — :3001 Nginx proxy → from_time + to_time
  • CLI — podman exec elk-analyser python cli.py run
  • ES Watcher — 備選（from_time + to_time）

資料管道

  • extractor.py — 外部 ES REST API + Checkpoint 讀寫
  • preprocessor.py — Trace ID 優先，fallback 時間窗口（5min）
  • bob_bridge.py — subprocess + @filename，本機直接呼叫
  • 欄位映射由 config.yaml field_mapping 可配置

Bob CLI（本機執行）

  • node:22-slim 基底 image，bob CLI 直接安裝
  • log-analyst custom mode — 因果鏈推理
  • 輸出契約：event_chains + summary JSON
  • 獨立邊界，未來可替換 AI 引擎

持久化

  • SQLite (elk_db) — analysis_jobs + checkpoint 表
  • from_time 優先序：from_time → lookback_minutes → Checkpoint → fallback
  • PPTX 報告存於 elk_reports volume，API 可下載
  • Elasticsearch 為外部服務，不在 compose 內
