啟動流程

  • podman-compose up → web（Nginx）+ elk-analyser（FastAPI）啟動
  • 無排程程序，等待 Kibana Alert Webhook / 手動觸發
  • from_time 優先序：from_time → lookback_minutes → Checkpoint → fallback
  • GET /jobs 查詢歷史，GET /jobs/{id}/report 下載報告

Bob CLI（本機執行）

  • node:22-slim 基底，Bob CLI 直接安裝於 elk-analyser container
  • bob_bridge.py 以 subprocess.run 直接呼叫
  • 事件序列寫入 bob_workspace/logs/job-{id}.json
  • bob run --mode log-analyst @file → 解析 last_message

Volume 設計

  • bob_workspace：bob_bridge 暫存 JSON，分析後刪除
  • elk_reports：PPTX 落地，API /jobs/{id}/report 可下載
  • elk_db：SQLite 單寫者，container 重建資料保留

外部 Elasticsearch

  • 不在 compose 內，為企業既有 ELK 叢集
  • config.yaml elasticsearch.mode 切換 mock / local / remote
  • 開發階段用 mock/sample_logs.json 不需連外
  • field_mapping 可配置，不綁定特定 ELK schema
